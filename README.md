# DISH DASH DOSH

Angular 22 concept portal for circular student essentials. Seven lazy-loaded views cover the student landing page, a separate university partnership page and dashboard, two starter kits, the student pre-order flow, campus surplus marketplace, and design iterations.

## Run locally

Use Node 22.22.3+ or 24.15.0+ (or 26.0.0+), then run:

```bash
npm install
npm start
```

Build with `npm run build`. The output is in `dist/`.

The catalogue contains a Dinnerware Kit and a Cookware Kit. Prices and exact contents are intentionally omitted until confirmed. Figures, listings, audit records, and checkout interactions are illustrative mock data from `DatasetService`. No payment, order, or university system is connected. The circular impact mark is an interactive preview of a planned QR history, not a scannable code.
